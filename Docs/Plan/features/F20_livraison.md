## Objectif

**Un lien cliquable** qui lance le jeu dans le navigateur, et un dépôt qui donne envie de recruter son auteur.

## Sous-parties

1. **Le déploiement continu** : chaque tag `vX.Y.Z` publie automatiquement le build WebGL (GitHub Pages ou itch.io, à trancher).
2. **Le versionnage** : SemVer, un `CHANGELOG.md` généré à partir des Conventional Commits.
3. **Le README portfolio** : GIFs de gameplay, schéma d'architecture, points techniques expliqués, liens vers les ADR et les cours, badge de CI.
4. **Les médias** : un trailer court et des captures.
5. **Une licence** pour le code, et les crédits des assets.

## À trancher au début du jalon

L'hébergeur (GitHub Pages contre itch.io), et la licence du code.
