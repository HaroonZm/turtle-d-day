# ADR 0002 : moteur Unity 6.3 LTS

- **Statut** : Accepté
- **Date** : 23/11/2026

## Contexte

Le projet a été créé en Unity 6000.0.74f1. Le support standard de Unity 6.0 LTS s'est terminé en octobre 2026. Unity 6.3 LTS est supporté jusqu'en décembre 2027.

## Décision

Migrer vers **Unity 6000.3.25f1 (6.3 LTS)** pendant que le projet est encore vide.

## Conséquences

- (+) Correctifs de sécurité et de plateformes, fonctionnalités récentes (UI Toolkit, URP, multijoueur).
- (−) Il faudra reconsidérer la prochaine LTS vers fin 2027.
